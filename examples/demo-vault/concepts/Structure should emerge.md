An empty knowledge base does not need an elaborate taxonomy. Repeated topics
and navigation problems reveal which structure is worth maintaining.

[[Maps of content]] should appear around active clusters. [[When tags stop
helping]] is a signal to replace broad labels with stronger links or a map. A
[[Weekly review]] is enough to notice these patterns without reorganizing on
every edit.
