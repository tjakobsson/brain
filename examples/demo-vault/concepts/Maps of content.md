A map of content is a maintained note that names a topic's important paths.
It gives a reader an intentional entry point without forcing every note into a
single folder hierarchy.

This vault currently branches into:

- discovery through [[Retrieval cues beat filing]]
- growth through [[Structure should emerge]]
- visual inspection through [[Graph density and trust]]
- lightweight classification through [[When tags stop helping]]

The map is useful because it makes choices. A generated list would only repeat
what the index already knows.
